# Aswesuma Benefits Application & Tracking System

## Overview

The Aswesuma Benefits Application & Tracking System is a full-stack web application developed to digitize the welfare benefit application process for the Nawalapitiya Divisional Secretariat in Sri Lanka. The system replaces the manual paper-based process with an online platform that allows citizens to apply for welfare benefits, submit claims and objections, and track their application status.

## Features

- User Registration and Login
- Online Aswesuma Benefit Application
- Submit Claims
- Submit Objections
- Application Status Tracking
- Admin Dashboard
- Officer Dashboard
- Application Review and Approval
- Category Assignment
- Claim and Objection Management
- Eligible Families List
- Contact Information Management
